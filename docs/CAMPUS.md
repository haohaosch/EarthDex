# 逢甲校園探索

`data/campus-species.json` 是可維護候選清單，目前12種全部 candidate，沒有虛構校內確認證據。`engine/campus.ts` 驗證 confirmed 須附來源、觀察日期與驗證者。新增校園/城市可沿用 regionId、candidate/evidence 結構。此版的逢甲周邊搜尋矩形只是探索視窗，不是地籍邊界，不能僅以落入矩形宣稱校內紀錄。

既有底部導覽與相機保留；頂部選單新增「逢甲校園」，可依圖鑑已解鎖/待探索/校內確認篩選、查看詳細分類來源與查詢外部研究紀錄。圖鑑 fcu/taiwan/birds 等系列共用單一解鎖 ID，徽章仍由伺服器結算。原有山林系列仍保留。

物種詳情會從後端 `/api/species/:id` 取得外部資料，同時保留本地文字與照片授權；API失敗不會阻擋既有圖鑑。
