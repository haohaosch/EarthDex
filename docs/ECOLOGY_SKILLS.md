# 八項生態技能：ecology-0.2 / official-2

這是現有引擎的新版，舊experimental-0.1與official-1保留。已開始對局仍走原規則、原始能力與重播；新對局與收藏的官方能力投影使用official-2。玩家實例、取得快照、原卡ID、原所有權不改寫，對戰不發卡。

## 已確認的規則

|技能|生效方式|次數|
|---|---|---|
|集體行為 Collective behavior|四鄰有翻面時，若翻面前與本卡同色，本卡在下一層跟著翻為同色|可重複，受3層連鎖上限|
|反捕食者防禦 Antipredator defense|只要任一比較方有此技能，就改用較小方向值勝出；相等不翻|可重複，防守方較小也反翻攻方|
|防禦性攻擊 Defensive aggression|被翻面後，下一層為新控制者比較所有相鄰敵牌|可重複，受3層上限|
|防禦機制 Defense mechanism|抵抗一次指向本卡的其他卡牌技能效果；原本便成立的普通翻面不抵抗|每局一次|
|逃避行為 Escape behavior|即將翻面時改退回原持有者手牌，控制者回原持有者，不產生翻面事件|可重複|
|擬態 Mimicry|抵抗一次翻面；不要求翻面來自技能|每局一次|
|遷徙 Migration|可放空格，或替換我方目前控制卡；舊卡回原持有者，算本次一回合並重新比較四鄰|可重複|
|掠食者 Predator|出牌後取得當下對手手牌快照；來源翻面後永久失效，離場也關閉原情報|每局一次，重返手牌不重置|

初始仍每人5張、同種至多2張；返手/替換可能超過9手。九格填滿結算；某方無合法動作自動跳過；雙方無合法動作或達100手以目前控制格數判勝，允許平手。AI自動跳過時可連續處理多手，最多到100手，不依賴前端補發操作。

## 事件順序與交互作用

遷徙返還舊牌 → 放置新牌 → 掠食者一次性情報 → 四鄰同一快照比點 → 收集待翻面 → 防禦機制（若由技能造成）→ 擬態/舊堅甲 → 逃避返手 → 同一波全部翻面 → 下一層集體行為與防禦性攻擊。技能連鎖最多額外3層；普通翻面本身不自動比較鄰牌。

- 防禦機制取消本次技能造成的待翻面，不重新跑一套普通比點；普通點數本來就足夠的進攻不會消耗此抵抗。
- 防禦機制在手牌中可以抵抗掠食者對**本卡**的查看；只遮住該張，不替整副手牌抵抗。使用後其他次查看可見。
- 逃避沒有「翻面」，不觸發依翻面發動的集體行為/防禦性攻擊。原持有者與目前控制者分開；不因返手改變正式卡牌所有權。
- 一次性次數與掠食者失效標記跟著該卡本局實例保留；翻色、遷徙、返手再出都不重置。
- 掠食者情報是時間點快照，未來補回手牌不持續更新；來源失效後關閉查看，不能抹除玩家已記得的資訊。
- 新版AI的hard搜尋只使用公開已出過的牌或自己有效的掠食者情報；未知手牌用中性估值，不能直接用伺服器保存的秘密能力預判。

## 資料、API與隱私

`engine/ecology-rules.ts` 是新版純引擎，`engine/versions.ts` 分流新舊規則。新增BattleCard.skillDisabled、BattleState.handReveals/turnSnapshots/endReason，皆是既有matches JSON內的向後相容欄位，沒有DDL或批次遷移。turnSnapshots保存回合末狀態，支援100手返手/替換重播與動畫；原initial/moves仍保留可重現。

所有對局API回應透過`server/battle-view.ts`：只回自己的手牌定義，對手牌只回不含物種/數值/技能的蓋牌；歷史動畫快照同樣遮蔽。掠食者情報只回授權viewer、有效來源，其他玩家拿不到。進行中的完整重播API回409，結束後才開放雙方完整重播；避免重播繞過掠食者。伺服器保存的完整對局仍保持權威，沒有使用客戶端卡牌定義結算。

UI加入我方格「遷徙替換」按鈕，拖曳也使用同一合法落點驗證；掠食者成功後可開啟情報視窗。技能觸發、抵抗、返手、翻面與較小勝出的比點都有提示。超過6手的重連追趕直接同步，不讓玩家等待長串動畫；「減少動態效果」直接同步結果。

## 固定能力、來源與預算

`data/card-balance-v2.json`是新的固定manifest，v1檔案不改。總預算仍28點，方向1–10，只有一項主要技能。這版技能成本依序為0、5、6、5、5、6、4、3，屬待持續模擬的遊戲平衡參數，不是生物學數據。

`data/trait-evidence-v2.json`列出9種有來源資格的物種：麻雀/臺灣獼猴集體行為、黑眶蟾蜍反捕食者、臺灣藍鵲防禦性攻擊、綠蠵龜防禦機制、疣尾蝎虎逃避、大鳳蝶擬態、家燕遷徙、翠鳥掠食者。新增ADW/Wikipedia頁面已實際讀取核對；Cornell/NOAA/既有ADW沿用先前核對來源。部分大鳳蝶雌型才擬態、各地家燕族群遷徙不同；遊戲資格不推定每個個體的行為。沒有足夠來源的物種仍中性，不任意編造特徵。

`node --import tsx scripts/build-official-cards.ts official-1`與`official-2`可以重現並核對，遇到已發布檔案不一致時拒絕原地覆寫。生物資料保育/原生狀態依然由來源資料處理，不能從技能反推。
