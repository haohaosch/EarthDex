# 遊戲技能與7張牌：tactics-0.3 / official-3

這版依玩家最新要求，把技能分配與動物習性完全分開。82種動物卡全部有一項遊戲技能；名稱、收藏說明、圖鑑預覽與指南明示遊戲能力不是生物知識。真實生態文字、圖片授權、辨識與觀察統計政策保留。舊experimental-0.1、ecology-0.2及official-1/2不重算，已開始對局仍用原快照。

## 數值與結算

- 全部卡牌四向基礎值1–10，最大最小至少相差3；數字1至10都有使用，沒有四個7的卡牌。
- 基礎值加技能成本共28。新成本依上述順序為0、6、6、5、6、7、5、10、6、7、9、7、7、9、8、8、5。成本是待實測的遊戲參數，非生物學量測。
- 固定物種/版本/種子分配，先雜湊排序後輪流分配17技能，讓每一技能有4或5種卡牌。沒有付費/稀有度加成，同種同版一致，不能旋轉或讀取重抽。
- 14與16的修正記在本局BattleCard.modifiers，不改寫官方CardDefinition。修正隨返手、翻色、覆蓋保留至對局結束；每次重新出牌可再發動。每方向增減後與動態比較值均夾在1–10。
- 放置/換防 → 可選換位 → 情報/落牌數值效果 → 同波快照比較 → 技能護盾 → 翻面護盾 → 撤離/植物消失 → 同時翻色 → 下一層技能。普通層0後最多3層技能，同波同一張牌最多額外攻擊一次，防止同時被多個來源重複排隊。
- 技能護盾抵抗遠攻/額外攻擊/逆轉/倒戈造成的翻面、削弱、換位或強制換防。友方正向鼓舞不消耗護盾；全場削弱即使來自友軍也可抵抗。被護盾阻擋的換位，仍在原落點普通攻擊；被阻擋的強制換防消耗本回合，來牌留手、盾牌留場，護盾消耗。
- 返手不等於翻面，不觸發倒戈/反擊/援擊。植物被擊破也不產生翻面連鎖。移動位置不等於翻色，不關閉情報；離場或翻色才關閉。

## 7張牌與植物開局

雙方各攜帶7張既有實例、同種最多2張、至少3種。開局第1與9格放置兩張**後手陣營**植物，四向分別3/4/3/4及4/3/4/3。植物在被擊破前**計入後手控制格**；成功攻擊後消失，立即扣分並騰空。植物不進手牌、圖鑑或收藏，不是可領取的動物卡。友軍換防/強制換防覆蓋相應陣營植物時也直接移除。

固定種子決定先手，植物陣營跟隨後手。九格滿、雙方無合法動作或100手結算，允許平手；單方無合法動作自動跳過。植物是先後手補償機制，不能僅靠開局配置就宣稱已達公平，另見模擬證據。

既有demo檔案若只選5張，會從原持有卡中補足7張並儲存，不新增卡；正式檔案由玩家自行選7張。舊對局的五張手牌不改動。對戰不授予、轉移或刪除正式卡牌所有權；強制換防僅影響本局手牌的陣營。

## 介面、權限與相容

手牌的點選與拖曳共用合法落點；我方換防、敵方換防各有按鈕。換位使用一次原子move請求，含可選swapCell；伺服器檢查相鄰敵軍、技能、回合及revision，不採用客戶端能力。AI列舉同一套換位選項。

出牌、數值變化、技能、抵抗、返手、換位、植物消失與翻色均依權威事件/快照播放。減少動態效果直接同步；斷線追趕過長直接同步。比點紀錄保存遠攻方向與當時總值，後續換色/返手不改寫歷史。

目前及歷史快照的敵手牌均在API遮蔽，只有有效情報偵察傳本人手牌快照。查看的是當時資訊，不持續更新；對局結束後才可完整重播。hard AI只用已公開卡牌與自己有效情報，不以未揭露手牌作弊。

無DDL、無正式卡牌批次遷移。舊官方manifest保持位元內容，三個版本均可用build-official-cards重現核對；規則分流保留兩個舊引擎。回滾到不認識tactics-0.3的Worker不能繼續新對局，應使用含三套規則的版本修復或先結束新局，不可用舊程式重算新戰報。
